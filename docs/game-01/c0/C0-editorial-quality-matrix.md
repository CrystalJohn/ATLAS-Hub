## Editorial signoff and test oracles

1. Bilingual educator independently reads each exact source excerpt, EN and VI field and intended skill/band. Record `reviewer identity/qualification/date/item revision/content hash/APPROVE or CHANGES REQUIRED/rationale`.
2. A second independent reviewer attempts to defend every distractor against the full goal. Any plausible competing answer quarantines the item. Author revision triggers review again.
3. Check the approved source-learning exposure route, question variants, feedback and source link using the **same published revisions**. A bank change invalidates old signoff unless explicitly covered by a reviewed patch policy.
4. Target A2–B1 learners paraphrase the task and failure rule, locate the confirmation action, explain a correction, and reach the exact lesson passage by keyboard/touch. No learner study was run here; record observed confusion and revise before calling it calibrated or usable.
5. Check first-try outcomes only among learners actually served each item; later-floor exposure is survivor-biased. No fabricated response counts, difficulty statistics or mastery thresholds.

Mechanical completeness is necessary; it does not satisfy these independent checks.
