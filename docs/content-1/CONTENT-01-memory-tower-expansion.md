# ATLAS CONTENT-01 — Memory Tower expansion

## Design contract

Memory Tower should review taught content, not invent new objectives at review time. Existing C0 evidence is recognition/controlled reading; it is not validated CEFR assessment, listening evidence or speaking mastery. New Tower items require a source ID, objective ID, answer rationale, feedback, retry variant and review status.

| Type | Purpose | Difficulty | Plausible bad distractors | Retry variation |
|---|---|---|---|---|
| Vocabulary recall | connect word to taught meaning/context | A1-A2 | same topic, wrong sense | new scene, same sense |
| Intent recognition | identify what speaker wants | A2 | response to another intent | change speaker/goal |
| Natural English | choose context-appropriate phrase | A2-B1 | grammatical but pragmatically off | change relationship/formality |
| Collocation | retrieve common word partnership | A2-B1 | literal L1 transfer | new noun/context |
| Context choice | fit phrase to social/professional setting | B1 | too formal/blunt | role and stakes change |
| Error detection | notice meaning-changing error | B1 | harmless variant marked wrong | repair a different error |
| Sentence reconstruction | sequence supplied chunks | A1-B1 | word-order confusion | add time/place chunk |
| Transfer challenge | apply same objective in new place | B1 | new vocabulary overload | keep core language, change setting |
| Boss challenge | two linked decisions | A2-B1 | second answer depends on first | alter route or information, not option order |

## Replay rules

- Keep the objective constant while changing a meaningful variable: location, role, destination, time, sign, order, or information gap.
- Do not count option shuffling as a new learning opportunity.
- Never penalize XP, World Travel, stamps or progress for an unapproved content error; reward and idempotency remain product contracts.
- Feedback must name the intent/meaning distinction and link to the lesson or source-backed note.
- A Tower floor may reuse a taught expression, but it must not introduce an untaught fare, platform, immigration rule, safety procedure or grammar point.
- Boss floor should show two atomic decisions and all-or-nothing submission only where the current contract explicitly requires it.

## Evidence boundary

The assessment principles are informed by [CEFR](https://www.coe.int/en/web/common-european-framework-reference-languages/cefr-companion-volume-and-its-language-versions), [IELTS listening task types](https://ielts.org/take-a-test/test-types/ielts-academic-test/ielts-academic-format-listening) and Cambridge’s [assessment approach](https://www.cambridgeassessment.org.uk/cambridge-approach/assessment/). These sources support design principles, not copied items or a claim that Tower performance validates CEFR.
