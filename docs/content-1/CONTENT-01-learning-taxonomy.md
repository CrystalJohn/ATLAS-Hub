# ATLAS CONTENT-01 — Learning taxonomy and evidence boundaries

## Skill taxonomy

| Skill | Observable evidence | Not established by |
|---|---|---|
| Vocabulary | select/recall meaning in taught sense and context | exposure alone or a dictionary lookup |
| Reading | interpret a written sign, notice, dialogue or short text | listening/speaking performance |
| Listening | identify intent/detail from an authorized recording | reading the transcript |
| Speaking rehearsal | construct or record a response under a defined rubric | selecting a response |
| Grammar-in-context | choose/construct form that changes meaning or appropriateness | isolated rule explanation |
| Pragmatics | choose a context-appropriate request, refusal, repair or apology | “polite” as one universal formula |
| Functional English | accomplish a practical communicative goal | knowing a phrase without using the goal |
| Cultural knowledge | identify a documented, scoped convention with region/venue limits | stereotypes or one anecdote |
| Reasoning | compare evidence and choose an action | trivia recall |
| Directions/navigation | map sign/instruction to a route or destination | authentic navigation beyond the simulated map |

## Interaction taxonomy

Select · Match · Order · Compose · Route · Inspect · Dialogue · Recall · Cloze · Categorize · Compare · Decision · Boss challenge.

## Context taxonomy

Airport · Train · Metro · Hotel · Restaurant · Café · Shopping · Emergency · Street · Museum · University · Workplace · Nature · Social life · Customer service · Phone call · Event.

## Cognitive demand

Recognition → Recall → Interpretation → Application → Transfer. Recognition alone should never be described as mastery. A Tower item can be valuable rehearsal while still being limited evidence.

## Content record minimum

Every authored unit should carry: stable ID, version, country/location, skill, interaction, context, objective, source basis, source claim type, target language, vocabulary senses, difficulty hypothesis, EN copy, VI support, distractors, explanation, retry family, review status, license status, author/date and publication gate.

## CEFR boundary

Use CEFR descriptors as design references from the [Council of Europe Companion Volume](https://www.coe.int/en/web/common-european-framework-reference-languages/cefr-companion-volume-and-its-language-versions). Label A1–B2 as an editorial estimate unless a validated assessment process supports a stronger statement. The current ATLAS C0 documentation correctly distinguishes recognition from productive recall, listening and mastery; preserve that distinction in future packs.

## Cultural evidence rule

Classify each cultural note as documented convention, common tendency, anecdotal behavior, regional variation or generational variation. Prefer official institutions, museums and universities; require a local reviewer for sensitive cultural, Indigenous, religious, health or emergency content. Never turn “often” into “always.”
