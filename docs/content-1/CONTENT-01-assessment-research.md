# ATLAS CONTENT-01 — Assessment and task-design research

## Boundary

Assessment sources are **REFERENCE ONLY**. ATLAS may borrow the underlying skill principle and author independent text, distractors, audio and answer keys. It must not copy proprietary test questions, passages, recordings, scoring rubrics or answer sets.

| [CEFR Companion Volume](https://www.coe.int/en/web/common-european-framework-reference-languages/cefr-companion-volume-and-its-language-versions) | descriptors distinguish communicative activities and levels | write objective as observable action: identify a sign, ask for clarification, obtain goods/services | descriptor alignment is a hypothesis, not validation of an ATLAS item |

## ATLAS design rules

1. Define the intent before the sentence: ask direction, clarify a restriction, purchase, apologise, report a problem, compare options.
2. Keep the construct narrow: one item should not secretly test vocabulary, route geometry, cultural trivia and grammar at once.
3. Distractors should represent plausible intent confusion, not spelling traps or unknown facts.
4. Feedback must explain why the choice fits the context and link back to the taught language.
5. Retry variation must alter context, order, role, time, destination or information—not only shuffle options.
6. Recognition, controlled construction and productive recall are separate evidence claims. Existing C0 is recognition/controlled reading and is not CEFR certification, listening evidence or speaking mastery.

## Suggested original item families

| Family | Skill evidence | Example ATLAS task | Bad practice to avoid |
|---|---|---|---|
| Specific information | reading/listening | choose which platform matches a spoken request | copying an exam transcript |
| Main purpose | listening/reading | identify why an NPC called | distractor differs only by one word |
| Matching | comprehension | match travellers to transport options | answer options not present in source |
| Sequencing | procedural reading | order check-in steps | testing memorised real-world policy not taught |
| Clarification | pragmatics | choose response when a sign is unclear | mark only one polite formula as valid |
| Transfer | application | same “ask for directions” intent in a museum | new vocabulary makes it a different lesson |
| Boss chain | two linked decisions | identify intent, then choose an appropriate reply | reward loss for an unapproved production failure |
