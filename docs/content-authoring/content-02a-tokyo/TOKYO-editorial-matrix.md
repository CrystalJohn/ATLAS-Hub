## Translation and assessment controls

- EN is canonical; the VI text is a candidate learner-support translation. It is not yet independently reviewed.
- The question stems have VI review candidates, but Tower’s scored English presentation should not show the translation before the response by default. If support is used in practice, label the evidence as supported. Never treat optional-VI exposure as independent English evidence.
- Choice strings remain English because the target is understanding/using the taught English. Do not silently auto-translate answer options.
- For each scored choice, the private key has one keyed response plus rationale for every option. Any second defensible answer blocks release or requires a reviewed accepted-answer set.
- Retry contexts change service/time, destination/line, label values, product/price, learner preferences, order, route or missing detail. No retry is only answer shuffling.
- Passage and candidate hashes link exact EN+VI lesson material. A wording change invalidates the dependent candidate review until hashes and signoffs are refreshed.
- No item claims CEFR validation, mastery, fluency or spontaneous productive ability. Compose/route interactions are still controlled or supported unless a separate rubric is reviewed.

## Release blockers

1. Independent bilingual educator review of every EN/VI pair and Tower variant.
2. Adversarial review of all distractors, accepted alternatives and answer uniqueness.
3. Validate the map/board visual support against the exact text; visuals are not yet authored.
4. Confirm local evidence supports any non-fiction Tokyo fact added later. Keep volatile routes, prices, schedules and venue rules fictional or re-verify them.
5. Approve any asset license/attribution and privacy/brand use before integration.
6. Script review and script lock before any audio generation.
7. A separate runtime authorization and content adapter review before app import or publication.

No educator, learner, legal, accessibility or audio review has been claimed as complete.
