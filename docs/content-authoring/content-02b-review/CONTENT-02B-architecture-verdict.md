# CONTENT-02B architecture verdict

2026-11-04 · PROVISIONAL · runtime integration NO-GO.

The documentation sidecar remains useful for authoring, but the r1 claim that hashes and reference membership demonstrate taught language is too strong. Concrete review found unused chunks, an unmodeled question form, unsupported map requirements and ambiguous menu questions that passed the verifier. Model fit is established for records, not for deployable content.

Current ATLAS TravelStep kinds are inspect/target/dialogue/route/order/compose; editorial match/compare/recall/decision and combined kind strings are not executable renderer definitions. CountryPack requires policy fields that should not be fabricated for this pack. Tower currently has a narrow source enum and bank schema; adding arbitrary new sources requires an explicit future adapter/schema decision under separate authorization, not silent conversion of docs into engine fixtures.

Maintainability test: a future Singapore MRT pack can reuse intent/scene/sense/chunk/source/review concepts if operator facts and teaching passages are newly authored. Do not copy Tokyo-specific types, line geometry or voice settings. Current CH-* strings are identifiers, not centrally resolved intent definitions; duplicate definitions will drift without a reviewed catalog. Regional vocabulary/register must remain local where meanings differ. London is only a representability example from 02A; no new country content was authored here.

Dialogue edits currently require JSON→Markdown regeneration but no durable generator existed in 02A, and review-signoff invalidation is only prose. 02B supplies executable checks and versioned proposals, not a content platform. Any integration must first show the neutral stimuli, reviewed source exposure, human reviews, stable IDs/revisions, server-only keys and unchanged progression/economy boundaries.
